# 🕵️‍♂️ Telegram Text Anonymizer Bot

Полноценный Telegram-бот на Ruby для потоковой анонимизации текстов и документов. Бот находит личные данные (имена, телефоны, IP-адреса, почты) и заменяет их на безопасные аналоги, либо жестко цензурирует в стиле спецслужб.

## ✨ Возможности

* **Два режима работы:**
    * **Обычный (Fake Data):** Заменяет найденные данные на реалистичные фейки (Иван -> Евгений, 8900... -> 8911...).
    * **Режим ЦРУ (Censor):** Закрашивает данные черными блоками `█████` по команде `/censor`.
* **Работа с документами:** Поддерживает загрузку и обработку файлов `.txt` и `.docx` с сохранением их структуры и кодировки (включая BOM для корректного отображения в Windows).
* **Умная подсветка цветов:** Находит в тексте упоминания цветов в любых падежах (красному, синей, желтые) и автоматически добавляет к ним соответствующие эмодзи (🔴, 🔵, 🟡).
* **Динамическое обновление базы:** Добавление новых имен для скрытия прямо из чата Telegram (без перезагрузки сервера).

## 🤖 Команды бота

### Для текста в чате
| Команда | Действие | Пример использования |
| :--- | :--- | :--- |
| `/start` | Выводит приветственное сообщение и инструкцию. | `/start` |
| `/add_name` | Добавляет новое имя в базу `names.txt`. Бот мгновенно перестраивает регулярные выражения. | `/add_name Алексей` |
| `/censor` | Включает режим жесткой цензуры (черный маркер) для конкретного сообщения. | `/censor Алексей звонил по номеру 89001234567` |

### Для работы с файлами
Бот автоматически обрабатывает файлы `.txt` и `.docx`. 
* **Обычный режим:** Просто отправьте документ в чат.
* **Режим ЦРУ:** Отправьте документ и напишите команду `/censor` в **подписи (caption)** к файлу перед нажатием кнопки "Отправить".
